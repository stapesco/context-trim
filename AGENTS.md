# AGENTS.md

> Machine-readable guidance for AI agents and LLM tool planners. If you are
> a human reading this, the [README.md](./README.md) is friendlier.

## What this is

A zero-dependency CLI that scans a local directory, respects `.gitignore`,
and emits a single Markdown digest suitable for pasting into an LLM prompt.
Reads source files, skips `node_modules` / lockfiles / binaries / VCS dirs.

## When to use it

Use it when **all** of these are true:

- You need to give an AI assistant context about a codebase.
- The codebase is small enough that one Markdown digest fits in the model
  context window (default cap 800 KB of digest, ~200 K tokens).
- You want to keep the source on disk (no upload to a cloud service).
- You want one command, no config, no API key.

## When NOT to use it

Do not use — pick an alternative — when any of these are true:

- The codebase is larger than the model's context window. Chunk with
  `repopack --split` or `gitingest` instead.
- The user wants semantic / embedding search. Use a vector store.
- The user needs language-aware parsing or AST extraction. This tool reads
  files as text.
- The user needs token counting. Use `repomix` (tiktoken-based) or
  `gpt-tokenizer` directly.
- The user needs compression / summarisation. This tool emits source verbatim,
  truncated per file.

## Install

```bash
# Use without installing:
npx stapes-context-trim /path/to/repo

# Pipe directly into an LLM prompt:
npx stapes-context-trim . | pbcopy   # macOS
npx stapes-context-trim . | xclip    # Linux

# Get a structured summary instead of the full digest:
npx stapes-context-trim . --json
```

No installation step. No `npm install -g`. No config file.

Requires Node.js 22.12.0 or newer. The tool exits with code 2 on anything
older.

## Output shapes

### Default: Markdown digest (stdout)

````markdown
# Codebase Context: my-project

Generated by stapes-context-trim v0.1.3
Root: `/Users/you/my-project`
Files: 142
Bytes: 487123

---
## src/index.ts
```ts
import { foo } from "./util.js";
foo();
```
## src/util.ts
```ts
export function foo() { return 1; }
```

---

End of digest.
````

Each file becomes a `## <relative path>` section followed by a fenced
code block. The fence length is picked to be strictly greater than the
longest run of backticks in the body so embedded ``` blocks inside a
source file do not terminate the outer fence. The fence is followed by
a language hint inferred from the file extension (`.ts` → `ts`,
`.py` → `python`, `.json` → `json`, and so on). When a file body
exceeds `--per-file-chars`, the renderer truncates it and appends a
marker line:

```markdown
[truncated: original 12450 chars, showing 49980]
```

The number after `showing` is the exact number of source characters
emitted before the marker. When the running total exceeds
`--max-total-chars`, the digest stops and the trailer is appended.

### `--json`: structured summary (agent-friendly)

```json
{
  "tool": "stapes-context-trim",
  "version": "0.1.3",
  "root": "/Users/you/my-project",
  "fileCount": 142,
  "totalBytes": 498688,
  "elapsedMs": 41,
  "skipped": {
    "binary": 18,
    "lockfile": 4,
    "tooLarge": 2,
    "gitignored": 1284,
    "unsupportedType": 96,
    "empty": 4,
    "excluded": 3210
  },
  "fileList": [
    { "path": "src/index.ts", "size": 412, "lines": 18 },
    { "path": "src/util.ts", "size": 89, "lines": 4 }
  ]
}
```

Each entry in `fileList` is `{ path, size, lines }`: the relative path
from the scan root, the on-disk size in bytes, and the LF line count.
The list is ordered by UTF-16 code unit, so the order is identical on
every machine regardless of locale.

The `skipped` counters cover every file the scan did not return:
`binary`, `lockfile`, `tooLarge`, `gitignored`, `unsupportedType`
(dropped for an unrecognised extension or filename), `empty` (zero
bytes), and `excluded` (always-excluded directory or minified asset).

## Exit codes

| Code | Meaning |
|---|---|
| 0 | clean run |
| 1 | invalid args (unknown flag, unparseable number), or a scan path that does not exist or is not a directory |
| 2 | Node.js below the supported minimum (22.12.0) or version string that cannot be parsed |

`--version` and `--help` always exit 0 and write only to stdout.

## Default skip rules

Layers, outermost first; a file is skipped if anything matches.

**Always-excluded directories** (matched at every depth):
`node_modules/`, `.venv/`, `.next/`, `.nuxt/`, `.turbo/`, `.vercel/`,
`.vite/`, `.cache/`, `__pycache__/`, `dist/`, `build/`, `out/`,
`target/`, `coverage/`, `vendor/`, `.claude/`, `.playwright-mcp/`,
`.git/`, `.svn/`, `.hg/`.

**Minified assets:** any file whose name matches `*.min.js` or
`*.min.css` (case-insensitive).

**Named lockfiles** (exact basename match):
`package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `bun.lock`,
`bun.lockb`, `Cargo.lock`, `composer.lock`, `Gemfile.lock`,
`Pipfile.lock`, `poetry.lock`, `uv.lock`, `go.sum`. Custom lockfiles
that do not match a name in this list are caught by `.gitignore` or
the size limit, not by name.

**Other:**

- Binary files (NUL byte in the first 8 KB)
- Empty files (`size === 0`)
- Files above `--max-file-bytes` (default 204800 / 200 KB)
- Symlinks (off by default); with `--follow-symlinks`, link targets
  are `realpath`-checked against the scan root and rejected if they
  escape
- Files whose extension is not in the recognised text set. The set
  covers common code, config, markup, and build-file names
  (`.ts`, `.js`, `.py`, `.json`, `.md`, `.yaml`, `.sh`, `Dockerfile`,
  `Makefile`, …). Anything else is dropped on extension alone.

`.gitignore` is honoured at every directory level. Nested
`.gitignore` files apply to files at their depth and below,
matching `ignore`-library semantics.

## Common flags

| Flag | Default | What it does |
|---|---|---|
| `--out <file>` | stdout | write digest to file (the file is excluded from the scan) |
| `--max-file-bytes N` | 204800 | skip files above N bytes |
| `--per-file-chars N` | 50000 | truncate each file body at N chars |
| `--max-total-chars N` | 800000 | stop emitting once digest hits N chars |
| `--follow-symlinks` | false | follow symlinks (off by default) |
| `--verbose` | false | log progress to stderr |
| `--json` | false | emit JSON summary instead of Markdown |

## Telemetry

None. Zero network calls. The only I/O is reading source files from disk
and writing to stdout or `--out`.
